# MAK(e) It Happen Moments, LLC

Landing page for MAK(e) It Happen Moments, LLC — event production and day-of coordination across Dallas–Fort Worth.

**Live site:** https://makeithappenmoments.com/

## Hosting (Cloudflare Pages)

The site is served by Cloudflare Pages from this repository's `main` branch, at **makeithappenmoments.com**.

- Every push to `main` publishes automatically, usually within a minute.
- Cloudflare project settings: framework preset **None**, no build command, output directory `/`.
- Custom domains in the Pages project: `makeithappenmoments.com` and `www.makeithappenmoments.com`.
- GitHub Pages stays on only to forward the old address: each page sends visitors from `mkahan17.github.io/Mak-e-It-Happen-Events-LLC/...` to the same page on makeithappenmoments.com.

## Notes

- `index.html` is fully self-contained: every photo, font, and script is embedded, so there are no broken links and nothing else to upload.
- Inquiries come in through the "Check my date" form (emailed to makeithappenevents.dfw@gmail.com), or by text or email — buttons link to `sms:` and `mailto:`.
